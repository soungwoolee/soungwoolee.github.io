Ten of 263 account groups explain 70.8% of margin variance

309 accounts were merged into 263 groups so that offsetting entries cancel out. Hover a point for the account.

Each account group placed by the size of its monthly swing and how closely it moves with margin

Accounts were compared by how much they moved, not by their amounts. Production bonuses are a third the size of machinery depreciation, yet contribute four times as much to margin variance.

Why the analysis targeted margin: monthly profit, 2021–2025
Hold margin at its five-year average and the monthly profit line goes almost flat

Production profit by month, KRW billions. Actual profit swung by 1.4bn a month (one standard deviation); with margin held at its 0.9% average, revenue changes alone would have moved it by 0.04bn. So the analysis targeted margin.

CLV project

Built shared AI context so the whole team analyzed with the same definitions

Definitionsrule
A TV and soundbar bought together is a bundle, not a cross-purchase.
Proceduresskill
Ask what the analysis is for before writing any query. Reuse the 229-line customer-flow query skeleton.
Guardrailsrule
Never edit code the team has signed off. Write a new version instead.

We had no direct access to the client's database, so consistent definitions mattered more than usual. Nobody had to redo the same correction twice, and the team agreed on one meaning for every customer type.
